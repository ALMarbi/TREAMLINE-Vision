# TREAMLINE-Vision

مشروع متطور في مجال **الذكاء الاصطناعي والتعلم الآلي (AI & Machine Learning)**، يهدف إلى معالجة البيانات وتحليلها وتدريب نماذج متعددة ومقارنة أدائها.

يتضمن المشروع خوارزميات التعلم الآلي، وتقنيات التعلم العميق مثل **CNN وResNet18** لتصنيف الصور، بالإضافة إلى تقنية **Grad-CAM** لتفسير التنبؤات، وإمكانية تدريب النموذج على صور جديدة بشكل اختياري.

حقق نموذج ResNet18 دقة اختبار بلغت **92.43%** على مجموعة بيانات CIFAR-10، حيث صنّف **9,243 صورة بشكل صحيح من أصل 10,000 صورة اختبار**.

**الهدف من المشروع:** بناء بيئة عملية متكاملة لتجربة نماذج الذكاء الاصطناعي وتقييم دقتها وتحليل نتائجها وتحسين أدائها، مع عرض الرسوم البيانية وصور التنبؤات.
