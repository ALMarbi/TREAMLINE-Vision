# TREAMLINE-Vision
**STREAMLINE Vision Pro** هو مشروع متطور في مجال الذكاء الاصطناعي والتعلم الآلي، يهدف إلى معالجة البيانات وتحليلها وتدريب نماذج متعددة ومقارنة أدائها.

يتضمن المشروع خوارزميات التعلم الآلي، والشبكات العصبية العميقة مثل CNN وResNet18 لتصنيف الصور، بالإضافة إلى تقنية Grad-CAM لتفسير التنبؤات، وإمكانية تدريب النموذج على صور جديدة بشكل اختياري.

**فائدة المشروع:** تطوير نماذج ذكية لتحليل البيانات وتصنيف الصور، وقياس دقتها وتحسين أدائها، مع عرض النتائج والرسوم البيانية بصورة واضحة.
